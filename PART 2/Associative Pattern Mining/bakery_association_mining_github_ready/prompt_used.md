# Prompt Used

> Build an end-to-end GitHub-ready **association pattern mining / market basket analysis** project using a popular Kaggle retail transaction dataset.
>
> Follow the **CRISP-DM framework**:
> 1. Business Understanding
> 2. Data Understanding
> 3. Data Preparation
> 4. Modeling / Association Pattern Mining
> 5. Evaluation
> 6. Deployment / Business Actions
>
> Use a popular Kaggle dataset suited to association rule mining. Clean the transaction data, create baskets, mine frequent itemsets, generate association rules, and calculate support, confidence, lift, leverage, and conviction.
>
> Explain why lift alone is not enough and evaluate rules using both frequency and association strength.
>
> Include meaningful visualizations and a polished **data science admin dashboard** with business KPIs, top products, strongest cross-sell rules, and actionable recommendations.
>
> Keep the repository minimal. Include only:
> - one executed Jupyter notebook
> - README.md
> - prompt_used.md
> - images/
>
> Do not add unnecessary source-code folders, requirements files, model files, or raw datasets. The notebook should obtain the public dataset itself and contain a small real-data fallback so it remains reproducible.
