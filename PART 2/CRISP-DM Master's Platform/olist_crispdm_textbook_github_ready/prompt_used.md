# Prompt Used

> As an industry expert data scientist and expert in CRISP-DM methodology, build an end-to-end textbook-quality data science capstone using a popular Kaggle dataset.
>
> Use the Brazilian E-Commerce Public Dataset by Olist so all analytical techniques share one coherent business setting.
>
> Follow CRISP-DM in depth:
> 1. Business Understanding
> 2. Data Understanding
> 3. Data Preparation
> 4. Modeling
> 5. Evaluation
> 6. Deployment / Synthesis
>
> The notebook must teach nuances, assumptions, data grain, join fanout, leakage, metric choice, business validity, monitoring, and iteration.
>
> Include data-science quizzes with answer keys for each major concept.
>
> Include:
> - exploratory data analysis
> - data preprocessing
> - unsupervised clustering using RFM + K-Means
> - anomaly detection using Isolation Forest
> - supervised classification
> - associative rule mining using support, confidence, and lift
> - sub-linear similarity search using MinHash Locality-Sensitive Hashing
> - a clean final synthesis showing how every technique answers a different business question
>
> Use real Kaggle Olist CSVs when available and provide a clearly labeled deterministic Olist-shaped fallback so the notebook remains executable without Kaggle credentials. Never present fallback metrics as Kaggle results.
>
> Keep the GitHub repository minimal:
> - one Jupyter notebook
> - README.md
> - prompt_used.md
> - images/
>
> Include a polished admin dashboard, CRISP-DM workflow visual, modeling visuals, LSH diagram, and synthesis map.
